# Query-plan prepared example

A seven-slide fictional-library lesson with four activities:
selective index, broad scan, join order and limited hash workspace.
All numbers and solutions are derived from the adjacent JSON sources.

Use the [authoring guide](../../docs/query-plan-authoring.md) for isolated
installation, enablement, PDF/PowerPoint builds and direct pdfLaTeX exports.
Version 0.3.0 displays prepared static exercises and implements the classroom
protocol. The phone selector editor and presenter controls are not implemented yet.

The lesson JSON contains teacher answers. Distribute the generated exercise
handout or static PowerPoint for student work; keep source JSON and solutions
with the instructor. The cost model preserves duplicate rows and uses teaching
cost units, rather than elapsed time.
