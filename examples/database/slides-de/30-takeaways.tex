\begin{frame}[t]{Welche Belege beantworten die Frage?}
Machen Sie mit der Aktivität den Denkweg sichtbar.
\medskip
\begin{itemize}
\item Ein Anfrageergebnis belegt das Verhalten auf den gegebenen Daten.
\item Eine Umformung braucht Regelvoraussetzungen; ein Schlüssel Minimalität.
\item Prüfen Sie Verlustlosigkeit und Abhängigkeitserhaltung getrennt.
\item Ein zulässiger Baum oder Ablauf darf von der Musterlösung abweichen.
\end{itemize}
\note{Welche neue Zeile, Abhängigkeit, Operation oder Seitenteilung würde eine plausible falsche Antwort entlarven? COVERAGE.md enthält den Aktivitätsindex. Jede Folie liegt in einer eigenen Datei.}
\end{frame}
