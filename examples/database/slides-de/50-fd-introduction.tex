\begin{frame}[t]{Aus fachlichen Regeln folgern}
Die Workshop-Aufgaben geben ein Schema und funktionale Abhängigkeiten vor.
\medskip
\begin{itemize}
\item Berechnen Sie Attributabschlüsse mit produktiven FD-Schritten.
\item Finden Sie einen und dann alle Schlüssel; begründen Sie Minimalität.
\item Beweisen Sie eine Folgerung oder bauen Sie ein Gegenbeispiel aus zwei Zeilen.
\item Wenige eindeutige Beispielzeilen begründen noch keine funktionale Abhängigkeit.
\end{itemize}
\note{Die Übungsaufgabe liefert direktes Feedback ohne Punkte. Die anderen sieben Aufgaben haben jeweils 100 Punkte. Nutzen Sie das jeweilige Schema: Die Beispiele haben absichtlich unterschiedliche Abhängigkeiten.}
\end{frame}
