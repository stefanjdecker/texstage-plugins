\begin{frame}[t]{Operationen verzahnen, Ergebnisse erklären}
Jede Aufgabe modelliert gespeicherte Lesewerte und Schreiboperationen.
\medskip
\begin{itemize}
\item Sagen Sie Endwerte vor dem schrittweisen Ablauf voraus.
\item Belegen Sie direkte Konflikte mit Operationspaaren.
\item Geben Sie einen Zyklus oder eine serielle Reihenfolge an.
\item Reparieren Sie den Ablauf unter Erhalt der Programmreihenfolgen.
\end{itemize}
\note{Starten Sie Vorhersagen, dann Ausführung untersuchen, Konflikte erklären, Reparieren und Auflösen. Die Transaktionsaktivität bietet formatives Feedback ohne Ranglistenpunkte. Sie simuliert weder Isolationsstufen noch ein vollständiges DBMS.}
\end{frame}
