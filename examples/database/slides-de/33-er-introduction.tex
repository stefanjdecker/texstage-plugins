\begin{frame}[t]{Von der Zeichnung zur Modellentscheidung}
Auf dem Campus gibt es auch Workshops: ein unabhängiges Szenario.
\medskip
\begin{itemize}
\item Eine Person kann mehrere Workshops besuchen, ein Workshop mehrere Personen haben.
\item Je Person-Workshop-Paar gibt es höchstens eine Anmeldung mit eigenem Status.
\item Wählen Sie ein Modell, prüfen Sie die Handyvorschau und speichern Sie.
\item Vergleichen Sie gültige Alternativen und Gegenbeispiele zu schwächeren Modellen.
\end{itemize}
\note{Die frühere Skizze bleibt eine offene Diskussionsaufgabe. ER Decisions prüft begrenzte Modellentscheidungen zu Anmeldungen, keine beliebigen Zeichnungen. Prüfen Sie Antworten privat, bevor Sie sie anonym teilen.}
\end{frame}
