\begin{frame}[t]{Split tables without losing meaning}
Assume atomic values. Keep three questions separate.
\medskip
\begin{itemize}
\item Normal form: which dependencies cause redundancy?
\item Lossless join: can we always reconstruct the original relation?
\item FD preservation: can we enforce the rules within the smaller tables?
\item Compare two decompositions and inspect the evidence for each.
\end{itemize}
\note{The examples retain their student/course and tutoring scenarios. Do not infer dependencies from the library data. Accept any answer satisfying the requested properties; exact equality with the worked decomposition is unnecessary.}
\end{frame}
