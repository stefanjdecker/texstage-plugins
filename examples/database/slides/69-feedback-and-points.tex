\begin{frame}[t]{What does a saved answer mean?}
Acknowledgement, evaluation and feedback release are separate events.
\medskip
\begin{itemize}
\item Save explicitly. A pending answer is saved but not yet checked.
\item Keep the presenter open: its restricted workers evaluate answers.
\item Discuss a shared answer anonymously, then reveal the worked evidence.
\item Scored examples contribute according to their displayed rule; reset withdraws awards.
\end{itemize}
\note{Built-in quizzes here have no points. B+ and normalization have 1,000 fixed points, FD has 100 except its practice task, and query-plan has timed quiz scoring. Coordinate, ER, relational and transaction examples are practice. See TEACHING.md; physical-phone acceptance is still a separate rehearsal.}
\end{frame}
