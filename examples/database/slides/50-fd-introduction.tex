\begin{frame}[t]{Reason from business rules}
The workshops now provide a small schema and explicit functional dependencies.
\medskip
\begin{itemize}
\item Compute closures using productive dependency steps.
\item Find one key, then every key, and justify minimality.
\item Prove an implication or construct a two-row counterexample.
\item A few unique sample rows do not establish a functional dependency.
\end{itemize}
\note{The practice task has immediate formative feedback and zero points. The other seven tasks have 100 points each. Work from each printed schema; different examples intentionally have different dependency sets.}
\end{frame}
