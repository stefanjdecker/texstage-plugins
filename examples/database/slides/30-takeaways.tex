\begin{frame}[t]{Choose the evidence that answers the question}
Use the activity to make reasoning visible.
\medskip
\begin{itemize}
\item A query result is evidence for the supplied data.
\item A rewrite needs its rule's conditions; a key needs minimality.
\item A decomposition needs separate losslessness and FD checks.
\item A legal tree or schedule can differ from the worked answer.
\end{itemize}
\note{Ask learners which new row, dependency, operation or page split would expose a plausible wrong answer. COVERAGE.md is the reusable activity index; each frame is in its own file.}
\end{frame}
