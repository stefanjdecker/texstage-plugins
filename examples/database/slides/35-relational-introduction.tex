\begin{frame}[t]{Give a query a visible structure}
Use this section's printed relations and data; their column names differ from the SQL seed.
\medskip
\begin{itemize}
\item Build the tree with relation, selection, join and projection controls.
\item Inspect an intermediate relation to explain what each node contributes.
\item Then rewrite an existing tree with checked transformation rules.
\item These exercises use \textbf{sets}: duplicate tuples disappear.
\end{itemize}
\note{Construction checks finite visible/private instances. Rule-based rewriting establishes equivalence only under the selected rule's stated conditions. The visual preview is not the private grader.}
\end{frame}
