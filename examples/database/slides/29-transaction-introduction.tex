\begin{frame}[t]{Interleave operations, then explain the result}
Each exercise is a small model of remembered reads and writes.
\medskip
\begin{itemize}
\item Predict final values before stepping through the execution.
\item Diagnose direct conflicts with operation-pair witnesses.
\item Give a cycle or serial-order certificate.
\item Repair the order while preserving each transaction's program.
\end{itemize}
\note{The former static lost-update preview is now the working counter activity. Start Predict, step through Inspect, then Diagnose, Repair and Reveal. Transaction version 1 gives formative feedback and no scoreboard points. It does not simulate isolation levels or a full DBMS.}
\end{frame}
